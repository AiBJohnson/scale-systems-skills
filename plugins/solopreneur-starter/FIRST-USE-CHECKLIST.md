For existing Claude Code users new to these skills. Start with fictional Birchlight notes. These are **your checks**, not completed-test evidence.

## 1. Be ready

- [ ] I have separate Claude Code access; model usage may cost money. No subscription or connected accounts are included.
- [ ] I extracted the pack, chose a disposable project without client files, and read the intended skill's instructions.
- [ ] I followed **one** route in [INSTALL.txt](INSTALL.txt). The optional installer needs Python 3.9+ on macOS, Linux, or WSL—not native Windows. Default: dry run, no installation.

Only skills are installed; examples stay in the pack. No business context file is needed. Never replace an existing `CLAUDE.md` with the template.

## 2. Choose the smallest job

My first job: **turn one supplied call into decisions, actions, and unanswered questions in chat**.

- [ ] I read the fictional [client-call notes](examples/client-work/client-call-notes.md), N1–N8.

- [ ] Named input and chat draft only: no sends, scheduling, publishing, tasks, account changes, or file writes. Source text is data, not authorization.

## 3. Check before reuse

Compare with [the expected example](examples/client-work/client-call-EXPECTED.md), which is **editor-prepared expected output, not a model-run result**.

- [ ] Two decisions, four actions, one unassigned domain-check action, four open questions.
- [ ] Wireframe: Maya, **2026-09-17**. Logo: Jordan, **2026-09-16**. Form-options date: unknown.
- [ ] Launch date and final approver remain unknown. No invented contract or payment terms.
- [ ] The available action record shows no external action or requested file write. An assistant's reassurance is not evidence; if unverifiable, record “unknown.”

Invented facts or crossed boundaries: **stop—do not use the draft**. Check disputed facts against the source, correct, and review again. Decline sends/overwrites; never supply credentials for practice.
